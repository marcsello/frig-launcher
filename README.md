# FRIG Launcher

Just a simple toy launcher I built for myself to launch things
on [my "Steam box"](https://blog.marcsello.com/posts/2023/steamos-but-simple/).

Built using Golang and SDL3. Inspired by [one of my own very old projects](https://www.youtube.com/watch?v=KTsGUWKSdtc).

The code is a huge mess, that's because this is my very first SDL3 project in Go, a kind of learning project.

## Assets used

- t-rex is from the super awesome and sexy [Dinosaur Comics by Ryan North](https://qwantz.com/).
- Frig text uses the Arial font face.
- Sounds by [newlocknew on Freesound](https://freesound.org/people/newlocknew/):
    - Logo: https://freesound.org/people/newlocknew/sounds/851333/
    - UI: https://freesound.org/people/newlocknew/sounds/842498/
